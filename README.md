# 중개사 복습 (웹)

공인중개사 시험 **민법 및 민사특별법** 문제 복습용 웹앱입니다.
아이폰·안드로이드·PC 어디서나 같은 주소로 쓰고, 사파리에서 **[홈 화면에 추가]** 하면
앱처럼 깔리며 인터넷 없이도 돌아갑니다.

- **1364문제**(문제집 373 · 부록 기출지문 100 · 합격서 본문 빈칸 891)를
  5문제 안팎의 섹션으로 나눠 학습 단위로 씁니다.
- **합격서**(스캔본 164쪽)를 앱 안에서 넘겨 볼 수 있고, 문제를 풀다가
  머리글을 누르면 그 대목이 바로 펼쳐집니다.
- **합격서 빈칸**은 점수를 매기지 않는 연습입니다. 1회독 진도에는 넣지 않고
  복습만 챙깁니다(20초 안에 맞히면 복습에서 빠집니다).
- **오늘 할 일 = 오늘 복습할 묶음 + 오늘 나갈 새 묶음** (복습이 먼저).
- 묶음 하나를 끝내면 **3·7·15·30일** 뒤 복습 일정이 잡힙니다.
- 기록은 이 기기의 브라우저에만 저장됩니다([풀고 또 풀자]에서 내보내기/가져오기 가능).

## 파일

| 파일 | 하는 일 |
|---|---|
| `핵심.js` | 점수·묶음·복습 규칙과 저장소 |
| `화면.js` | 화면 그리기 |
| `모양.css` | 모양 (문제 화면은 문제집 지면처럼) |
| `데이터.js` | 문제 자료 — **만들어지는 파일** |
| `sw.js` | 오프라인용 |

문제의 원본은 안드로이드 앱 저장소(`bank-sensor-backend`)의
`android-app/app/src/main/assets/` 하나뿐이고, 거기서 `데이터.js`를 뽑아 옵니다.
점수·복습 규칙은 안드로이드 앱(Kotlin)과 같아야 하므로 한쪽을 고치면 다른 쪽도 같이 고칩니다.
